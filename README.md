# GamesFree.gg

GamesFree.gg is a browser-game discovery website with free online games across action, adventure, arcade, puzzle, sports, multiplayer and other categories.

## Start playing

**[Visit GamesFree.gg →](https://gamesfree.gg/)**

**[Explore all games →](https://gamesfree.gg/free-online-games/)**

**[Play word puzzles →](https://gamesfree.gg/word-puzzles/)**

Open a game page to read its instructions and check its controls. Availability, loading, advertising and device support can differ between titles.

## About this repository

This repository contains a small static introduction page for GamesFree.gg, designed for GitHub Pages. Its visit buttons link to the main website. It does not contain the WordPress theme, database, backups or embedded game files.

Games remain the work of their respective creators.
